## 1. 通用

- [ ] 目标平台已确认（单端即可）
- [ ] App icon 1024 不透明，iOS/Android 各尺寸已接入
- [ ] splash-screen 在目标端显示正确，无拉伸/裁切
- [ ] 版本号/Build 号正确且递增
- [ ] 若使用 mock：无 localhost/测试域名泄漏，mock 数据不含真实用户信息
- [ ] 若 P0 有后端：环境地址正确、接口兼容
- [ ] 无调试菜单/测试后门/测试账号
- [ ] 无密钥/证书明文入库
- [ ] 崩溃上报/性能/埋点启用
- [ ] 本地/远程开关可用（按 P0）
- [ ] 隐私政策/服务条款可访问
